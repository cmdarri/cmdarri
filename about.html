About

About CmDarri

CmDarri is a small software development organization founded by VaiTns. The team develops practical applications with a focus on quality, accessibility and affordable software.

What we build

CmDarri builds Android applications for tasks that are common enough to be annoying and narrow enough to do properly. The current catalogue covers three areas: batch media conversion, photo-sequence timelapse stabilisation, and on-device artificial intelligence.

A shared thread runs through all of them. The work happens on the device. Bulk Vid to MP3 Converter Free runs its conversions through native FFmpeg libraries on the phone. FrameLock performs its eye detection and object tracking locally. CmDarri - Offline AI keeps both the model and the conversation on the handset. That choice is about speed, offline reliability and data handling at the same time, and it is a deliberate one.

The organisation is small. The same people who write the software publish it, support it and answer the email. That is also why the pricing is modest — there is no large organisation here whose overhead has to be recovered from the download.

Philosophy

How the work is approached

Four commitments that shape what gets built and what gets published.

  1. 01

    On-device first

    If a task can be done on the phone, it is done on the phone. It is faster, it works without a signal, and it avoids handing user files to a server.

  2. 02

    Offline is the baseline

    Core features should not need a connection. Where a download is unavoidable — an AI model, for example — it happens once and is made explicit.

  3. 03

    Honest descriptions

    Only features that are actually shipped get listed, on the store listing and here. No roadmap items presented as existing functionality.

  4. 04

    Affordable by design

    Small, focused utilities priced so that installing one is an easy decision rather than a considered purchase.

How privacy is handled

Each published application has its own privacy policy, written for that app and reflecting what it actually does. They are not copies of a single template with the name swapped.

CmDarri does not operate a backend for the published applications. There is no account system, no analytics integration and no advertising SDK in any of them. The policies on this site set out which permissions each app requests and why, and what happens to files a user selects.

Where an app does reach the network, the policy says so plainly. CmDarri - Offline AI, for example, contacts a model hosting service once, and only when you personally choose to download a model file.
