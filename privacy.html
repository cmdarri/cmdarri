This website

Privacy of the CmDarri website

What this website is

This site is a set of static HTML, CSS and JavaScript files. There is no server-side application, no database, and no account system. The pages you request are files, not records generated about you.

What this website does not do

The code that makes up this site contains none of the following:

  • Analytics, telemetry or usage-tracking scripts
  • Advertising or ad-network code
  • Cookies set by CmDarri, or any local storage used to identify you
  • A contact form, or any mechanism that would receive and store a message you submit
  • Third-party embeds such as social media widgets, chat widgets or video players

Fonts are the one external resource this site requests. They are loaded from Google Fonts when you open a page; your browser therefore makes a request to that service, which is governed by Google’s own privacy terms rather than by CmDarri.

Email

The contact address on this site is a plain email link. Choosing to write to it hands your message and your email address to your own email provider, and the resulting conversation is stored by that provider. CmDarri uses the address only to reply to you or to handle the request you sent.

Hosting

The site is hosted on GitHub Pages. Like any web host, GitHub processes technical request information such as IP addresses in order to deliver pages, under GitHub’s privacy statement. That processing is GitHub’s, not CmDarri’s.

Application data

The privacy policies linked above apply to the applications, not to this website. Each describes what that individual app does with information on your device. Where the two differ, the application policy is the relevant one.
